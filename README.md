# 🧠 P-Reinforce 지식 자동화 위키

> **Andre Karpathy의 LLM-Wiki 아키텍처 x 강화학습(RL) 기반의 자율 지식 정원사 엔진**

파편화된 원시 데이터를 스스로 읽고, 의미론적으로 분류하며, 지식 간 양방향 그래프를 연결하여 영속적인 '외부 뇌'를 구축합니다.

---

## 📂 디렉토리 구조

```plaintext
위키에이전트/
├── .agents/skills/p-reinforce/  # P-Reinforce 에이전트 스킬 정의
├── 00_Raw/                     # [불변] 사용자 입력 원본 데이터 (날짜별 보관)
├── 10_Wiki/                    # [자동 구조화] 자율 지식 층
│   ├── Projects/               # 🛠️ 목표 중심 (진행 중인 일, 프로젝트 요약)
│   ├── Topics/                 # 💡 개념 중심 (스스로 확장하는 개념 분류)
│   ├── Decisions/              # ⚖️ 의사결정 중심 (판단 이유, ADR)
│   └── Skills/                 # 🚀 실행 중심 (프롬프트, 워크플로우 패턴)
├── 20_Meta/                    # [시스템] 엔진 두뇌 데이터
│   ├── Graph.json              # 지식 간 연결 그래프 (노드 & 엣지)
│   ├── Policy.md               # 강화학습 분류 정책 및 피드백 기록
│   └── Index.md                # 위키 전체 목차 (TOC)
└── README.md                   # 시스템 안내
```

---

## 🚀 사용 워크플로우

1. **원시 데이터 투척 (`00_Raw/`)**:
   - `00_Raw/YYYY-MM-DD/` 폴더에 자유롭게 메모나 노트를 작성하거나 붙여넣습니다.
2. **P-Reinforce 실행**:
   - 대화창에서 *"P-Reinforce 실행해줘"* 또는 *"00_Raw 정리해줘"* 라고 지시합니다.
   - 에이전트가 문서를 분석하여 `10_Wiki/` 내 적절한 카테고리에 Karpathy 템플릿 형태로 변환/생성하고 `Graph.json` 및 `Index.md`를 자동 갱신합니다.
3. **피드백 및 강화 (RL Feedback)**:
   - **칭찬/승인**: *"분류 마음에 든다"* → 해당 주제 유사도 가중치 상향.
   - **수정/이동**: *"이건 Topics/Coding이 아니라 Projects/로 옮겨줘"* → 카테고리 경계선(Boundary Shift) 재설정 및 Policy.md 업데이트.
