## 💡 [FINAL DESIGN BRIEF] 손실 기반 에러/경계 조건 컴포넌트 세트 (v1.0)

**목표:** 시스템 오류 발생 시 사용자가 기술적 실패(Technical Failure)에 초점을 맞추지 않고, 현재 데이터나 기능의 한계로 인해 **놓치고 있는 최적의 기회비용($T_{loss}$)**을 인지하도록 유도한다.

**핵심 원칙 (The Mindset Shift):**
*   **❌ Bad:** "503 Service Unavailable. 서버 점검 중입니다." (기술 책임 회피)
*   **✅ Good:** "최적 경로 검색 실패. 현재 필터 범위($X$일)에서는 $T_{loss}$가 예상됩니다. 상세 분석을 위해 [Advanced Report]를 이용하세요." (사용자 행동 유도 및 가치 강조)

---

### 🎨 I. 비주얼 시스템 가이드라인: 경고/손실 인지 단계

| 요소 | 설명 | 규격 및 사용법 |
| :--- | :--- | :--- |
| **경고 컬러** | 손실, 기회비용의 위험을 나타내는 색상. (Warning / Danger) | **Primary Red:** `#CC3333` (핵심 경고 텍스트/하이라이트). <br> **Secondary Red:** `#FFDDDD` (배경색 - 매우 약한 배경 강조).<br>**Icon Color:** `#CC3333` (아이콘 색상). |
| **경고 아이콘** | 일반적인 느낌표(⚠️) 대신, '막힌', '경계'를 상징하는 아이콘 사용. | 🔴 (빨간색 원 안에 흰색 `!` 또는 삼각형 경고 마크). <br>**사용 위치:** 에러 메시지 제목 옆, 핵심 버튼 앞. |
| **폰트 강조** | $T_{loss}$ 값 및 제한 수치는 반드시 볼드 처리하고 `#CC3333`으로 하이라이트한다. | `[손실 기회비용: ₩150,000]`와 같이 구체적인 수치화된 손실 지표를 강조합니다. |
| **레이아웃** | 에러 메시지 전체 블록은 다른 컨텐츠와 분리하여, 경고 배경 (`#FFDDDD`)으로 처리하고, 중앙에 배치하여 시각적 집중도를 높입니다. |

---

### 🧱 II. 핵심 컴포넌트 세트 (3가지 상태)

#### 1. [API/데이터 누락 에러] - Missing Data Error
*   **상황:** 사용자가 요청한 데이터 조합으로는 최적의 경로를 계산할 수 없는 경우. (가장 흔함)
*   **목표:** '정보 부족'을 '결제 필요'로 치환한다.
*   **구조:** 경고 아이콘 ➡️ 헤드라인(손실 고지) ➡️ 본문(원인 설명 + 손실 지표 제시) ➡️ CTA (해결책).

| 요소 | 내용/카피 예시 | 비주얼 처리 및 가이드 |
| :--- | :--- | :--- |
| **제목** | 🔴 놓치고 있는 최적 경로가 있습니다. | `#CC3333` + `⚠️` 아이콘 사용. 가장 크고 두드러지게 배치. |
| **본문 (원인)** | 현재 설정된 필터 조건($X$ 지역, $Y$ 기간)만으로는 최소 10시간 이상의 최적 여정을 계산할 수 없습니다. 이로 인해 예상되는 **최소 손실 기회비용은 ₩XXX,XXX** 입니다. | '손실 지표'는 `#CC3333`으로 강조 처리. (ex: $\text{Loss} \approx \$250$) |
| **CTA 버튼 A** | **[Advanced Report로 손실 복구하기]** | 주 액션(Primary Action). 배경색을 짙은 색상으로 설정하고, 유료 기능 접근임을 명확히 함. |
| **CTA 버튼 B** | (선택 사항) 필터 조건 완화 및 재시도 | 보조 액션(Secondary Action). 회색 처리하여 가치를 낮춤. |

#### 2. [경계 조건 에러] - Boundary Condition Error
*   **상황:** 사용자가 너무 넓은 범위(예: 1년 전체)를 요청하거나, 너무 많은 데이터 포인트를 한 번에 조회하려 할 때. (시스템 과부하의 간접적 경험)
*   **목표:** '범위 제한'을 '최적화된 분석 필요'로 전환한다.
*   **구조:** 경고 아이콘 ➡️ 헤드라인(제한 고지) ➡️ 본문(근본 원인 제시 + 가이드 제공) ➡️ CTA (단계별 접근 유도).

| 요소 | 내용/카피 예시 | 비주얼 처리 및 가이드 |
| :--- | :--- | :--- |
| **제목** | ⚠️ 너무 광범위한 요청입니다. 최적화 분석이 불가능합니다. | 경고 아이콘 사용. '불가'라는 단어보다 '비효율적'이라는 표현을 선호. |
| **본문 (원인)** | 한 번의 API 호출로는 수백 개의 데이터 포인트를 통합 계산하기 어렵습니다. 최상의 결과를 얻기 위해서는 [지역별/테마별]로 분석 범위를 쪼개야 합니다. | 분할 접근 방식을 시각적으로 설명하는 작은 다이어그램(mini-diagram)를 삽입하여 이해도를 높임. |
| **CTA 버튼** | **[추천: 지역 A와 B로 나누어 분석하기]** | 사용자가 다음 단계로 나아갈 구체적인 가이드라인을 제시하며 CTA를 만듦. (가장 중요한 것은 '다음에 무엇을 해야 하는지' 명확히 알려주는 것) |

#### 3. [요청 초과 에러] - Rate Limit Exceeded
*   **상황:** 사용자가 무료 플랜의 API 호출 한도 또는 분석 크레딧을 모두 소진했을 때. (가장 직접적인 수익화 지점)
*   **목표:** '제한' 자체를 '프리미엄 가치 입증'으로 활용한다.
*   **구조:** 경고 아이콘 ➡️ 헤드라인(소비 고지) ➡️ 본문(남은 가치 설명 + 비교 제시) ➡️ CTA (즉각 구매 유도).

| 요소 | 내용/카피 예시 | 비주얼 처리 및 가이드 |
| :--- | :--- | :--- |
| **제목** | 🔥 분석 크레딧 소진. 최적화 기회비용이 발생했습니다. | `#CC3333` 하이라이트와 불꽃 이모지(🔥)를 사용하여 긴급성을 극대화. |
| **본문 (원인)** | 현재 사용하신 크레딧($X/Y$)을 모두 소진하여, 더 이상 실시간 최적 경로 시뮬레이션이 불가능합니다. 무료 버전에서는 시간 기반 손실 예측이 어렵습니다. | 남은 크레딧과 소진된 크레딧을 그래프로 보여주어 '소비'를 직관적으로 인지하게 함. |
| **CTA 버튼 A** | **[Advanced Pass 구매하기] ($39.99)** | 가장 눈에 띄는 위치와 색상으로 배치. 가격이 곧 *손실 방지 비용*임을 강조. |
| **CTA 버튼 B** | (선택 사항) 간단 정보만 확인하고 나가기 | 회색 처리하며, 사용자가 이 경로를 선택하면 얻는 가치가 매우 낮음을 암시. |
