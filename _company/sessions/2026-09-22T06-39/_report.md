## I. 목표 설정
**목표:** '손실 인지' 기반의 보고서 서비스에 최적화된, 최대 LTV를 달성할 수 있는 Paywall/Pricing 구조 확립.
**핵심 원칙:** 사용자가 지불하는 비용이 '서비스 이용료'가 아닌, **'놓치고 있는 기회비용($T_{loss}$)'을 회복하기 위한 투자금**으로 인식되도록 설계한다.

## II. 가격 모델 비교 분석 (Pricing Model Comparison)
| 구분 | 모델 A: 프리미엄 구독제 (Subscription) | 모델 B: 아카이브 기반 패키지 판매 (Bundle/Service) | 모델 C: 하이브리드 결합 (Hybrid - 권고안) |
| :--- | :--- | :--- | :--- |
| **가치 제안** | 지속적인 '손실 감시' 및 업데이트된 최신 데이터 접근권. | 단일하고 강력한 임팩트(One-Shot Value). 특정 여행의 완벽한 계획 수립에 집중. | 기본적인 무료 사용으로 유입 -> Paywall에서 위기감 조성 -> 고가치 보고서 구매 또는 저가 구독 연계. |
| **가격 구조** | 월 $9.99 ~ $14.99 (API 요청/크레딧 기반) | 건당 $29.99 ~ $49.99 (고화질 Advanced Report 1회 판매) | 기본 Free Tier (매일 3건 제한) + **Advanced Report ($39.99)** + 연간 구독 할인 패키지 ($99) |
| **주요 수익원** | 반복 매출 (MRR), 트래픽 기반 크레딧 판매. | 높은 객단가(ARPU). 즉각적인 현금 유입. | 초기 안정적 매출 확보 + LTV 극대화 조합. |
| **강점** | 예측 가능한 안정적 수익 흐름, 충성 고객 확보 용이. | 고가치 기능에 대한 명확한 가치 증명 (Loss Recovery 경험). | 신규 진입 장벽 최소화, 최고 가치 상품으로의 전환율 극대화 유도. |
| **약점** | 사용자가 필요성을 느끼기 전까지는 구독을 유지하기 어려움. | 고객에게 '다시 올 이유'를 제공하지 못할 위험 (One-Off Risk). | 구조가 복잡하여 초기 UX 설계에 디테일이 많이 요구됨. |

## III. 핵심 KPI 및 ROI 예측 (Assumption: 10,000명 활성 사용자 기반)
*   **KPI 측정 지표:** Paywall 전환율(CVR), 평균 고객 생애 가치(LTV).
*   **전제 조건:**
    *   평균 사용 주기(Trip): 3개월 (여행 계획/실행 -> 다음 여행 시작)
    *   Advanced Report 구매 가능 사용자 비율: 20% (10,000명 중 2,000명)

| 모델 | 예상 CVR (Report 기준) | 평균 결제액 (ARPPU) | LTV 추정치 ($/사용자) | ROI 전망 |
| :--- | :--- | :--- | :--- | :--- |
| A: 구독제만 | 1.5% (약한 유도) | $30 (월 평균) | $200 - $250 | 안정적, 하지만 낮은 객단가로 인해 성장에 한계. |
| B: 패키지 판매만 | 4% (강력한 필요성 자극) | $45 (최대치 활용) | $180 - $230 | 높은 단기 매출 달성 가능하나, 재방문 유도에 어려움. |
| **C: 하이브리드 결합** | **3% (균형 잡힌 자극)** | **$75 (Report + 연간 구독 시 할인)** | **$400 - $550** | **가장 높음.** 초기 진입 장벽을 낮추고, 가장 강력한 수익원(Advanced Report)으로 전환시키는 구조. |

## IV. 최종 권고 (Decision Recommendation)
**✅ 모델 C: 하이브리드 결합 전략 채택.**

*   **선정 근거:** 현 서비스의 핵심 강점인 '손실 리스크 정량화'는 단발성 고가치 상품(Advanced Report)으로 판매할 때 가장 높은 가치를 인정받습니다. 여기에 구독 모델을 결합하여, **단기적 현금 유입과 장기적인 사용자 락인(Lock-in)** 효과를 동시에 달성해야 합니다.
*   **실행 우선순위:**
    1.  **MVP Phase:** Advanced Report ($39.99) 판매에 집중하여 초기 수익을 확보하고, 이 과정을 통해 사용자가 '손실 회복' 경험의 가치를 체감하게 한다. (모델 B 핵심 기능 활용).
    2.  **Scale-up Phase:** Model A의 요소를 추가합니다. Advanced Report 구매 횟수나 크레딧 소진량에 따라 할인된 연간 구독 옵션($99)을 제안하여 LTV를 극대화한다.
