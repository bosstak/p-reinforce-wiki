# ✨ 최종 UI/UX 컴포넌트 세트 디자인 브리프 (v1.0 - Master Specification)
**프로젝트:** bosstak 아카이브 서비스
**목표:** 기술적 실패를 '정보의 기회비용 손실'로 재정의하고, 사용자 행동을 유료 전환 또는 정보 탐색으로 유도한다.
**범위:** 모든 경계 조건 및 오류 발생 시 노출되는 통합 모달/팝업 시스템 정의.

## Ⅰ. 디자인 원칙 및 스타일 가이드라인 (Design System)

| 요소 | 정의 | 상세 스펙 | 비고 |
| :--- | :--- | :--- | :--- |
| **Primary Color** | 브랜드 신뢰도, 행동 유도 | `#2B6CB0` (Deep Ocean Blue) | CTA 버튼, 주요 링크. |
| **Accent Color (Success)** | 성공, 정상 로딩 완료 | `#4CAF50` (Soft Green) | 데이터 로드 성공, 긍정적 피드백. |
| **Warning/Error Color** | 경고, 손실 가능성 ($T_{loss}$), 실패 | `#D32F2F` (High Alert Red) | *모든 오류 및 Paywall 영역에 필수 사용.* |
| **Background/Neutral** | 기본 배경색 | `#FAFAFA` (Off-White) | 콘텐츠 가독성을 높임. |
| **Typography (H1, H2)** | 제목, 강조 | Pretendard Bold / 32px - 48px | 크고 명확하게 시선을 사로잡음. |
| **Typography (Body)** | 본문 설명 | Pretendard Regular / 16px - 18px | 정보 전달의 안정성을 확보. |

## Ⅱ. 핵심 컴포넌트 상세 디자인 스펙 (Component Specifications)

### 1. 경고/오류 발생 모달: The Loss Alert Pop-up
**(사용 시점: API 호출 실패, 데이터 누락 등 기술적 경계 조건 발생)**

*   **목표:** 사용자에게 '시스템 오류'가 아니라 '정보 접근의 제한'이 있음을 인식시키고, 다음 행동을 유도한다.
*   **스타일:** 화면 중앙 오버레이 (Dimmer Overlay) 방식. 배경 콘텐츠는 흐리게 처리 (`opacity: 0.5`).

| 요소 | 스펙 및 레이아웃 | 내용/카피라이팅 원칙 | 개발 가이드라인 |
| :--- | :--- | :--- | :--- |
| **아이콘 & 컬러** | 모달 상단 중앙에 큰 경고 아이콘 (⚠️). 배경은 `#FCEEED` (Soft Red Background). | 감성적/위험 신호 전달. 기술 실패가 아님을 강조. | 반드시 `$T_{loss}$`와 연관되는 색상 사용. |
| **제목 (H2)** | **[놓치고 있는 기회비용]** 또는 **데이터 접근에 제약이 있습니다.** (`#D32F2F` 굵게) | 기술 용어(Error, Failed) 절대 금지. 손실 관점의 제목 사용. | 최대 2줄로 제한하여 가독성 확보. |
| **본문 (P)** | 코다리가 정의한 원인 명시: "현재 요청하신 [지방 아카이브] 정보는 [크레딧 부족/유효 기간 만료]로 인해 접근할 수 없습니다." | 사용자에게 친절하게 상황을 설명하되, 본질적으로 '결제'가 필요함을 암시. (현빈 가이드라인 적용) | 간접적 위협(Soft Threat) 메시지 구조 유지. |
| **손실 지표 영역** | 모달 중앙 하단에 박스 형태 (`#FFF3E0` 배경). $T_{loss}$ 수치와 공식을 시각적으로 분리. | **현재 예상 손실 기회비용 ($T_{loss}$): 1,520 크레딧**<br/>*남은 크레딧: 80 / 필요: 160.* (최대 한도를 기준으로 계산된 수치) | 이 영역이 모달의 가장 중요한 시각적 초점(Visual Focus)이어야 함. |
| **CTA 버튼** | 주 CTA: **[Pro Plan으로 즉시 해결하기]** (`#2B6CB0` 배경, 흰 텍스트). 보조 CTA: [다른 아카이브 탐색] (링크 스타일). | 가장 쉬운 해결책(유료 결제)을 최우선 배치. | `onClick` 이벤트는 Paywall 모달로 이동하도록 설계. |

### 2. 유료 전환 모달: The Premium Paywall
**(사용 시점: 특정 핵심 기능에 대한 접근 제한 발생)**

*   **목표:** 무료 버전의 한계를 명확히 보여주고, 유료 전환을 통해 얻는 가치(Value)를 압도적으로 인지시킨다.
*   **스타일:** 전체 화면 모달 (Full-screen Modal)로 깊은 몰입감을 제공한다.

| 섹션 | 디자인 스펙 및 레이아웃 | 콘텐츠 구성 요소 | 비즈니스 로직 반영 |
| :--- | :--- | :--- | :--- |
| **헤더** | "1인 크리에이터의 모든 가치를 경험하세요." (H1) / 핵심 기능 아이콘 묶음. | 서비스의 궁극적 가치(Freedom, Depth, Completeness)를 상징하는 문구 배치. | 감성적 연결고리 구축. 기술적 제한이 아닌 '경험의 한계'로 포장. |
| **비교 구조** | 2단 분할 레이아웃 (Free vs. Premium). Free는 흐릿한 회색 박스, Premium은 선명하고 풍부한 색상으로 강조. | **[무료]** : 핵심 기능 제한(예: 아카이브당 1건) / **[프리미엄]**: 모든 무제한 접근 (Unlimited Access). | 사용자가 자신의 현재 '결핍'을 직접 확인하게 유도하는 것이 핵심. |
| **가치 강조 영역** | 가장 중요한 비교 항목에 대해 별도의 애니메이션/아이콘(`✨`)으로 포인트를 준다. | *예시:* "지방 아카이브 전체 지도 데이터베이스 접근" (Free: X / Premium: ✅) | '누락된 기능'을 시각적으로 강렬하게 표현해야 함. |
| **CTA & 결제 유도** | 가장 크고 눈에 띄는 버튼 (`#2B6CB0`). 가격과 기간(월별/연간) 옵션을 명확히 제시. | "Premium Access (무제한 아카이브 탐험)" / `onClick` 시 결제 플로우 시작. | $T_{loss}$와 연계하여, '오늘 구매하지 않으면 놓치는 기회'를 카피로 삽입. |

### 3. $T_{loss}$ 수치 표시 위젯 (Widget)
**(사용 시점: 네비게이션 바나 푸터 등 지속적으로 노출되어야 할 영역)**

*   **목표:** 시스템의 '감시자(Guardian)' 역할을 하여, 사용자에게 현재 자신이 가진 정보/가치의 제한을 상기시킨다.
*   **위치:** 최상단 헤더 또는 사이드바 측면 고정 위치 (Sticky Element).
*   **디자인 스펙:**
    *   배경: 미묘하게 경고를 주는 `#FFF8F5` 배경 사용.
    *   요소: **[⚡️ 남은 기회비용]** 아이콘과 굵은 글씨로 $T_{loss}$ 수치 (예: `(120/160) 크레딧`).
    *   상태 변화: 크레딧이 임계점 이하로 떨어지면, 배경색을 점진적으로 `#D32F2F`에 가깝게 변화시키고 애니메이션 효과를 추가한다. (시각적 경고 극대화)
